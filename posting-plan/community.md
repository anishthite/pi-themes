## Pi GitHub Discussions

**Title:** Show and Tell: Pi Themes — 68 themes with an in-terminal picker

> I published **Pi Themes**, an installable Pi package with 68 themes and a `/themes` picker.
>
> - Live preview while navigating
> - Dark/light theme grouping
> - Save the selection with `/themes set`
> - Optional terminal-background preview via OSC 11
>
> Install:
>
> ```sh
> pi install npm:@anishthite/pi-themes
> ```
>
> Repository: https://github.com/anishthite/pi-themes
>
> Demo video: attach `output/pi-themes-catalog.mp4`
>
> Theme requests and bug reports are welcome in the repository.
