## Hacker News

**Title:** Show HN: Pi Themes – 68 themes with an in-terminal picker

**URL:** https://github.com/anishthite/pi-themes

**First comment:**

> I built this because Pi’s default themes are intentionally minimal, but I wanted fast palette exploration without leaving the agent.
>
> `pi install npm:@anishthite/pi-themes` adds 68 themes and `/themes`: arrow through live previews, press Enter to keep one, and use `/themes set` to persist it. It also supports an opt-in OSC 11 terminal-background preview where terminals allow it.
>
> The project is MIT-licensed. I’m especially interested in which palettes or terminal behaviors should be added next.
